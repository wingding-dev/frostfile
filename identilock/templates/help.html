Help & FAQ

Straight answers to the questions everyone asks. Click a question to open it.

Is my information being sent anywhere?

No. Identilock is a program on this computer, not a website or a service. Everything you type is saved into one scrambled (encrypted) file on this machine — the same way a photo you save stays where you put it. The only exceptions are buttons that say so out loud: the Breaches page (which asks a public leak-checking service a question when you press Check) and the “Check All Links Now” button on the Sources page (which visits agency websites to see if they still exist). Neither sends your personal information anywhere, and neither runs unless you press it.

What does it do with the Social Security numbers?

Two things, and only two. The last-4 digits are shown next to names so you can tell whose record is whose. The full number — which you don't have to enter at all — is printed into the freeze request letters the app generates, because the agencies require it on the letter. Skip it and letters print a blank line to fill in by pen.

What if I forget my passphrase?

Use your recovery code — the XXXXX-XXXXX-XXXXX-XXXXX code you were shown and asked to print when the vault was created. On the unlock screen, click “Forgot your passphrase?”, enter the code, and pick a new passphrase. Each code works once; you'll be handed a fresh one to save.

There is no reset without that code — nobody can look your passphrase up or override it, which is exactly why nobody can read your data either. Lose both the passphrase and the code, and the data is gone. (No code saved? Settings → Recovery Code issues one while unlocked.)

Doesn't a freeze lock ME out too? What does it take to undo?

Undoing is the easy part, and it's free. For the major agencies you lift a freeze online or by phone in minutes — temporarily, for just long enough to apply for the loan or open the account — then it goes back on. You are not signing up for a commitment; you're putting a deadbolt on a door you rarely use. Each agency's page in the Directory has its exact “to undo” steps.

I'm getting a new computer. How do I move Identilock?

One file. On the old computer: Settings → “Package Everything for the Move” — that puts a single file on your Desktop. Carry it over on a USB stick, install Identilock on the new computer, and choose “Moving from another computer?” on its first screen. Same passphrase as before. Old backups can stay behind; the new computer starts making its own.

Copying the file is fine — nothing ties it to one machine. And if the USB stick gets lost, the file is scrambled: without your passphrase it's gibberish, and guessing passphrases against it is deliberately slow math that makes brute force impractical against a real passphrase.

What if this computer dies?

Identilock backs itself up about once a week (Settings shows where). Those backups live on this same computer, though — so for real disaster protection, use “Package Everything for the Move” every few months and keep that file on a USB stick in a drawer. It's scrambled, so the drawer doesn't need to be Fort Knox.

Why do some things say “FYI — nothing to do”?

Because being honest beats looking busy. Some companies keep files about you but offer no step a person can take. They're listed so you know they exist, kept off your to-do grid, and never counted against your progress.

Where do the addresses and phone numbers come from? Can they go stale?

Every fact points at a source page you can click (the little numbers, and the Sources page). Green means a person actually read that page on the date shown; yellow means it's a pointer to check yourself. Agencies do move their PO boxes — the “Check All Links Now” button on the Sources page tells you if any source page has gone dead, which is your cue to double-check before mailing anything. Directory corrections arrive with app updates.

Why is this free? What's the catch?

No catch. It was built for one family after a breach and shared onward. There's no company, no account, no data collection — which you can verify, because there's no network activity to collect it with.

Something looks wrong — a dead link, a changed address.

Don't mail anything to an address you doubt — check the agency's own site, and tell whoever gave you this app so the fix reaches everyone.
