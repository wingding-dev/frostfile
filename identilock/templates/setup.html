Set Up Identilock

Identilock is a program on this computer, not a website or an online service. There is no account, no company on the other end, and nothing you type is sent anywhere — it all lives in one file on this machine, the same way a photo or a video you save does. Pick a passphrase; it scrambles (encrypts) that file so only you can read it.

The passphrase cannot be recovered by anyone.

Nobody — not this app, not its author — can look it up or reset it for you. On the next screen you will get a one-time recovery code: print it and keep it somewhere physically safe. If you forget the passphrase, that code is the only way back in; lose both and the data is gone for good.

Moving from Another Computer?

If Identilock ran on your old computer, don't start over — on that computer, open Settings and press “Package Everything for the Move”, bring the file here, and load it below. Your passphrase stays the same one you used before.

What This App Does and Does Not Do

Identilock keeps track of the freezes and sign-ups you place yourself, and keeps the confirmation numbers and PINs straight. It is not a monitoring service: it has no connection to the credit bureaus, because federal law (the Fair Credit Reporting Act) only lets companies with an approved reason pull your report{{ cite(citer, refs('ftc-fcra')) }} — there is no version of that for an app like this. It reaches the internet only when you press a button — checking a leak, or checking that the agency links still work — never on its own.
