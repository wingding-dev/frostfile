Social Security Number

“Why would I type the number that just got leaked into yet another program?”

Fair question, and the answer is: you don't have to. Both boxes below can stay empty and everything in FrostFile still works.

If you do fill them in, the number is not given to anyone. FrostFile is not a website and there is no company on the other end — what you type is scrambled (encrypted) into a file on this computer, and it never leaves this machine.

Here is everything this software does with it:

  • Last 4 digits — shown on screen next to the name, so you can tell whose record is whose. That is the entire use.
  • Full number — printed into the freeze request letters this app generates for you (the agencies require it on the letter). Skip it and the letters print a blank line to fill in by pen. That is the entire use.

Just enough to tell whose record is whose. Not enough to do damage with.

Store the full number (off by default, on purpose)

The full number is only useful for one thing: printing mailing forms with it already filled in. If you skip it, printed forms leave a blank line and you write the number in with a pen — which is a perfectly good way to do it, and keeps the most sensitive number you own out of the file entirely.

If you do store it, it is scrambled with your passphrase like everything else. Just think about whether this computer's files get copied anywhere you would not want them.
